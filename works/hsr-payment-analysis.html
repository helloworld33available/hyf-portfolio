《崩坏：星穹铁道》付费系统拆解案

沿核心循环 → 付费点地图 → 数值模型的顺序拆解星铁付费体系，用 40 万次蒙特卡洛推演校验不同玩家层级拿到目标角色的期望成本与方差，并给出对配置表与定价的可落地结论。

撰写 / 2026.09 拆解分析 · 付费 + 蒙特卡洛 黄彦飞
目录

    一、概述

    1.1 游戏简介

    · 《崩坏：星穹铁道》是米哈游研发的二次元回合制 + 箱庭探索 + 卡牌养成 RPG，2023 年 4 月上线，与《原神》同属米哈游旗舰二游产品线。

    · 核心玩法为「队伍编成 → 回合制战斗 → 角色养成 → 高难副本验证」，商业化以角色 / 光锥（武器）抽取的跃迁系统为绝对主力。

    1.2 为什么拆这套系统

    1.2.1 玩家侧：消费者到底买到了什么

    · 画面感与情绪价值：抽卡演出、五星揭示的金光、角色立绘与专属剧情，把"付费"包装成了"相遇"，玩家买的不是数值段落，是一个可带入的角色。

    · 确定性下限：90 抽必出五星、歪后必出当期 UP。玩家能提前算出自己"最坏要花多少"，攒资源的行为因此变成了可规划的目标，而不是纯赌。

    · 零氪也能玩到底：忘却之庭、虚构叙事这类验证通道的最高奖励，0 魂 + 专武就能拿满。玩家不会因为不付费而被关在内容门外。

    · 时间可以换钱：星琼、星辉、星芒三条回收通道，让活跃度和付费之间可以互相折算，低氪玩家靠版本积累也能稳定拿到限定。

    1.2.2 策划侧：这套系统值得学的地方

    · 它把"随机"做成了可预期的随机：软保底 + 硬保底 + UP 判定继承三层结构，方差被锁在可控区间，舆论风险低。

    · 它把"武器池"这个行业公认的体验黑洞改好了：光锥池用 75/25 加歪后必出，取代了《原神》的定轨机制，期望抽数从约 105 抽降到约 64 抽。

    · 它把付费深度和验证门槛解耦：付费买的是余量和阵容宽度，不是通关资格，因此付费生态不会反噬 DAU。

    · 这套方法已被同一家公司复用到后续产品（《绝区零》音擎池沿用 75/25 + 歪后必出），说明它是被内部验证过的方法，不是孤例。

    1.3 拆解目的

    · 讲清楚它的方法：把跃迁系统的机制骨架、概率模型、资源投放与回收完整拆出来，而不是停留在"它保底很良心"这种结论。

    · 论证它为什么好：用具体数值（期望抽数、分位数、最坏情况、单版本投放）和玩家体验（双峰分布、歪一次的成本）做论据，横向对比《原神》《绝区零》《明日方舟》验证优越性。

    · 能复刻：站在设计者角度回答"如果我要把这套方法搬到另一个品类，我怎么搬"，给出元素级、模块级、变种、世界观包装四条路径。

    1.5 养成逻辑介绍

    在星铁的价值体系下，玩家的消费欲望主要来自三处产出不足：角色数量不足、光锥（武器）不足、养成材料不足。因此拆付费之前必须先拆养成。

    · 角色养成线：等级（上限 80）、行迹（技能树）、星魂（0~6 层）、遗器（套装 + 主副词条）。

    · 光锥养成线：等级（上限 80）、叠影（1~5 阶）。

    · 养成材料的产出被体力（开拓力）卡住，材料不足会直接推高"我要不要多抽一个角色 / 一把专武"的决策权重。

    · 结论：付费欲望的原点不是"想变强"，而是"验证通道要求的练度门槛 + 我想多玩几套阵容"。星铁把前者压得很低，把后者做得很宽，这是它付费生态稳定的根本原因。

    2.3 商品系统简介

    · 直购星琼：6 个固定档位，价格体系长期稳定，无大额折扣与返利，这一点与《原神》一致，是"账号保值"叙事的基础。

    · 周期性商品：小月卡（每日返还）、大月卡（按活跃度阶梯发放），两者都要求日常活跃才能拿满，用付费换 DAU。

    · 跃迁券：不直售，只由星琼兑换、活动赠送、星辉商店兑换三条路径产出，保证"抽卡"这件事在账面上始终等价。

    · 副产物商店：星辉商店、星芒商店，既是资源回收口，也是非酋玩家的兜底。

    2.4 付费系统在游戏框架中的位置

    层级内容与付费的关系
    核心循环层编成 → 战斗 → 养成 → 验证付费入口在"编成"之前：先有角色，才有循环
    内容层主线、活动、探索、模拟宇宙产出星琼与养成材料，是免费玩家的付费替代
    商业化层跃迁、月卡、大月卡、商店跃迁贡献绝大部分收入
    验证层忘却之庭、虚构叙事、末日幻影把付费成果转化为可展示的战绩，同时返还星琼
    回收层星辉、星芒、开拓力把抽卡副产物与体力转化为养成进度，闭合循环

    定位结论：跃迁不是"商城"，而是内容投放的唯一入口。它卡在核心循环的起点，因此付费与 DAU 是正相关而非互相挤压。

    · 4 星：10 抽硬保底，同样有 50% / 75% 的 UP 判定与歪后必出。

    3.2 玩家体验流程（四类玩家各自的路径）

    3.2.1 零氪玩家（低活跃）

    上线做日常 → 攒星琼 → 看版本前瞻决定要不要抽 → 攒不够就跳过当期 → 用四星光锥和常驻角色凑队伍 → 打忘却之庭拿一部分奖励。

    3.2.2 零氪玩家（全勤）

    全勤日常 + 活动 + 验证副本 → 单版本约 56 抽 → 平均每 1.4 个版本拿到一个限定角色（中位数口径）→ 队伍逐步成型 → 忘却之庭可满星。

    3.2.3 月卡 / 大小月卡玩家

    每天上线领 90 星琼 → 单版本约 76 抽 → 1.1~1.3 个版本一个大保底 → 有余量去抽光锥池 → 阵容宽度明显更宽，能同时应付忘却之庭与虚构叙事两套环境。

    3.2.4 中重氪玩家

    直购星琼补足差额 → 追星魂（1~6 层）与光锥叠影 → 目标不是"能打过"，而是"打得更快、能玩更多套阵容、在逐光捡金里把三套玩法都打满"。

    五、论据三：框架特点

    5.1 养成时间

    目标所需时间（估算）说明
    单个角色从 0 到能上场（等级 + 行迹 + 遗器成套）约 2 ~ 3 周受体力限制，付费体力可压缩到 1 周
    单角色遗器刷到主词条正确约 1 ~ 2 周副词条为长期目标
    一整套四人队伍成型约 2 ~ 3 个版本与角色抽取节奏基本同步
    追到能满星忘却之庭约 1 ~ 2 个版本前提是 0 魂 + 专武配置

    5.2 难度区间

    内容门槛配置目标玩家
    主线 / 活动 / 日常四星光锥即可全体
    模拟宇宙与常规副本0 魂 + 四星 / 活动光锥全体
    忘却之庭 12 层满星0 魂 + 专武，遗器主词条正确零氪全勤及以上
    虚构叙事满星0 魂 + 专武，需角色广度月卡及以上
    末日幻影满星弱点属性对得上 + 一支成型击破队零氪全勤及以上（看 box 广度）
    末日幻影·星启模式（三路）· 追高分三支独立成型队伍 + 高魂中重氪

    关键结论：付费门槛被压在"0 魂 + 专武"这一档，约 156 抽（折合约 2,504 元），或者月卡玩家攒两个版本。更高的付费深度全部落在"余量与阵容宽度"上，而不是通关资格上。

    5.3 机制特点

    · 大小保底（50/50 + 歪后必出）：把最坏情况锁死在 2 倍期望，方差可控。

    · 光锥池 75/25 且无定轨：这是星铁相对《原神》最大的体验改进，也是最值得复刻的一点。

    · 保底计数与 UP 判定跨版本继承：资源不会沉没，玩家敢攒。

    · 专票 / 通票分层：免费投放的限定资源不会被常驻池稀释。

    · 副产物回收（星辉 / 星芒）：把"运气差"折算成"时间可兑换"，是最重要的一条负反馈。

    · 结果页即结算：单抽十连都直接出结果页并支持分享，减少演出打断感。

    5.6 付费带来的实力占比

    分两层看：

    · 对"能不能打通"的影响：接近 0。忘却之庭满星的门槛是 0 魂 + 专武，零氪全勤也能达到，付费不设卡。

    · 对"打得有多舒服"的影响：约 80% ~ 120%。从 0 魂到 6 魂 + 满叠影，同角色战力大致翻倍（估算），体现在通关速度、容错率、可玩阵容数量上。

    这是星铁付费系统最重要的一条设计判断：把付费深度和验证门槛解耦。付费买的是余量，不是资格——所以重氪玩家的数值优势不会制造"不充钱就没法玩"的舆论，付费生态也不会反噬 DAU。

    5.10 验证方式

    · 星数制：忘却之庭按满星 36 星结算，玩家能直观看到自己"差几星"，目标非常具体。

    · 环境轮换：不同期数给不同的环境 buff，逼迫玩家换阵容，把"角色广度"变成可验证的指标。

    · 周期重置：两周一次的重置制造稳定的回归动力，也把养成进度切成可检查的阶段。

    · 产出返还：验证通道本身产出星琼，打本 = 攒资源，让"变强"和"继续抽"连成一条线。

    6.3 与《绝区零》的关系：方法被复用，说明它被验证过

    · 《绝区零》的音擎池沿用 75/25 + 歪后必出，与星铁光锥池口径一致。

    · 同一家公司在新产品上复用同一套武器池方案，说明这套方法在星铁上是跑通了的——它不是一次性设计，而是被内部验证后的标准做法。

    这一点对拆解很重要：判断一个方法好不好，最硬的证据不是它当下的数据，而是它有没有被复制到下一个项目。

    6.4 与《明日方舟》的思路对比：两种保底哲学

    · 明日方舟走的是"高硬保底 + 无 50/50"路线：300 抽必得当期限定，靠概率递增而不是 UP 判定来收敛运气。优点是绝对上限明确，缺点是期望之上仍有很大的长尾，运气差的人要吃满 300 抽。

    · 星铁走的是"低硬保底 + 50/50"路线：最坏 180 抽，期望 93.6 抽，靠 UP 判定收敛运气。优点是中位数体验好、上限低，缺点是玩家要额外承受"歪"这个事件。

    · 两条路都能成立，但星铁的方差更小、节奏更快，更适合 42 天一版本、每版本都有新 UP 的排期节奏。

    6.5 结论：它的方法好在哪

    · 把随机的方差锁进了一个可预告的区间：1.4 ~ 3.21 个版本必得限定，玩家能做规划。

    · 把最容易引起负面舆论的武器池改好了，并且这套改法被后续产品复用。

    · 把付费深度与验证门槛解耦，重氪的数值优势不制造门槛，付费生态不反噬 DAU。

    · 用副产物和验证通道产出把"运气"和"活跃"接起来，运气差的人可以用时间补。

    八、如果我来复刻：怎么搬到别的游戏里

    8.1 单个元素复刻

    · 「歪后必出」可以单独搬到任何有随机产出的系统：抽卡、开箱、随机词条洗练。做法是给每次随机结果打一个"是否命中目标"的判定，未命中则给下一次结果上锁。

    · 「软保底递增」可以搬到任何有次数累积的随机：强化成功率、掉落概率、招募次数。做法是在接近硬保底前的一段区间内线性抬概率，让硬保底几乎不触发。

    · 「副产物兑换」可以搬到任何有重复产出的养成：重复装备、重复碎片、重复图纸，统一折算成一种可换核心资源的代币。

    8.2 模块化复刻

    · 把整套跃迁做成一个可配置模块：卡池表（消耗 / 类型 / 保底分组）、概率表（基础概率 / 软保底起点 / 增量 / 硬保底 / UP 命中率）、权重表（奖池条目与权重）。

    · 换皮到别的品类时只需要改三张表：资源名（星琼 → 钻石）、道具名（光锥 → 武器/装备）、验证通道名（忘却之庭 → 竞技场 / 爬塔）。

    · 关键是把"保底分组"和"UP 判定"做成两个独立的状态字段，而不是写死在卡池里——这样才能支持跨池继承和后续扩展。

    8.3 变种设计

    · 变种一（降低方差）：把 50/50 改成 60/40 或 75/25，代价是常驻角色曝光下降。适合角色数量少、常驻池价值不高的产品。

    · 变种二（提高深度）：加入"定向 UP"——玩家可在候选里指定 1 个，歪了必出指定项。适合强调目标性的重度养成产品。

    · 变种三（换赛道）：把"抽角色"换成"抽技能 / 抽词条 / 抽阵容组合"，保底逻辑完全复用，只改产出物。适合 SLG、卡牌、自走棋。

    · 变种四（非抽卡化）：把保底逻辑用在"赛季奖励随机箱"上，让玩家在赛季内累积的开启次数能收敛运气。

    8.4 世界观本地包装设计

    · 星铁的包装是"跃迁"——抽卡被讲成在星海间跃迁、与角色相遇，金色流星是全屏演出的记忆点。

    · 搬到一个三国题材：包装成"求贤"，单抽是一次寻访，保底是"三顾"，歪了就是"得遇他人"，歪后必出是"诚心已至"。

    · 搬到一个赛博题材：包装成"数据抽取 / 义体适配"，保底是"适配度累积到 100% 必然成功"，软保底是"适配度曲线"。

    · 搬到一个武侠题材：包装成"结缘 / 寻访名侠"，十连是"广发英雄帖"，副产物是"名帖残页"，可换请帖。

    · 包装的要点：保底必须在叙事里有一个自洽的说法。玩家能接受的不是"系统给你保底"，而是"你的行为在叙事里累积到了必然的结果"。

    九、总结

    《崩坏：星穹铁道》的付费系统，是建立在坚固价格体系之上的一套"可预告的随机"。它先用硬保底加大小保底把运气锁进一个可预告的区间，再用光锥池的 75/25 无定轨把行业里最难做的武器池改好，最后用副产物回收和验证通道返还把"运气差"折算成"时间可以补"。

    而它最关键的一条设计判断，是把付费深度和验证门槛解耦：重氪玩家的数值优势不制造门槛，因此付费生态不会反噬 DAU，规模和内容消耗节奏都保得住。

    由此我认识到以下几点：

    · 付费内容必须与核心玩法高度绑定。星铁的付费入口卡在核心循环的起点，所以付费和 DAU 是正相关，而不是互相挤压。

    · 随机的设计目标不是"更刺激"，而是"方差可控"。真正决定口碑的不是期望值，是最坏情况和中位数之间的距离。

    · 规则必须能被玩家一句话复述。"歪后必出"比"命定值 + 定轨"更容易传播，传播成本越低，系统的舆论风险越小。

    · 判断一个方法好不好，最硬的证据是它有没有被复制到下一个项目。光锥池 75/25 被《绝区零》沿用，这就是它被验证过的证明。

    · 负反馈不能少。副产物兑换是这套系统里最不起眼、但最不能删的一块——它决定了运气最差的那批人会不会留下。

    十、拆解心得

    感谢您看到这里。

    本文为本人黄彦飞整理归纳总结。拆完《崩坏：星穹铁道》的付费系统，我最大的收获不是记住了 0.6%、90 抽、50/50 这些数字，而是意识到数值从来不是设计的目的，它只是把设计意图落到地上的手段。同样是 90 抽保底，配上"歪后必出"和"歪后要定轨"，玩家的情绪是完全不同的两种东西。

    以前我看一个抽卡系统，第一反应是算它贵不贵。现在我学会先问三个问题：运气最差的人会不会被卡死？规则玩家能不能一句话讲完？付费带来的优势会不会变成门槛？这三个问题问完，这套系统好不好，基本就有答案了。

    拆解这件事本身也改变了我学习游戏设计的方式。以前是看到什么记什么，现在是先问"策划当时为什么这么定"，再去找数值和体验上的证据。找不到证据就承认自己没看懂，这比硬凑一个结论要诚实得多。
