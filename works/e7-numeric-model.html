数值策划案

《第七史诗》数值策划四件套

以《第七史诗》为对象的数值策划四件套：养成线数值模型（目标→反推→公式→校验四步法，45 天目标周期闭环）、经济系统全局表（四货币 90 天收支模拟与通胀诊断）、战斗公式与行动验证（回合制口径）、数值结构拆解案（分层墙 / 卡池期望 / 战力曲线）。

撰写 / 2026.10 数值建模 · 回合制口径 黄彦飞

零．方法论主线

四件套共用一条主线：目标 → 反推 → 公式 → 校验。先定设计目标（45 天培养完成 / TTK 节奏 / 获取周期），反推资源产出与消耗参数，用公式生成全表，最后以校验页闭环——改一个参数，全表重算并即时显示达标或缺口。全部模型为公式活表，无一处手填死数。

作品证明的能力
① 英雄养成线数值模型目标→反推→公式→校验四步法；45 天目标周期闭环；90 天成长曲线
② 经济系统全局表四货币流量建模；90 天收支模拟；通胀诊断与回收口设计
③ 战斗公式设计与行动验证五因子伤害公式（回合制口径）；极端堆叠策略抑制；击杀轮数平衡判据
④ 数值结构拆解案从成品反推设计意图（分层墙 / 保底模型 / 战力曲线）

一．英雄养成线数值模型

1.1 反推链

设计目标：英雄培养完成（等级 60 + 六星 + 觉醒 5-5 + 装备强化 +15）周期 45 天。反推链：目标周期 × 标准玩家日产经验 → 总经验预算 → ÷ 等比和系数（59 级 ×1.05 递增求和 = 335.79）→ 每级经验基准 20,102 → 公式生成 60 级全表。日产出、递增率、等级上限全部为全局参数，改"目标周期"一个数，曲线基准与校验结论自动重算。

1.2 分层墙结构

墙内容周期性质
等级墙Lv1→60，企鹅经验（×1.05 递增）随经验线线性兑现快墙：新手期正反馈
升星墙1→6 星，金币 10/20/40/80/160 万 ×2 几何递增约 2 周中墙：中期目标
觉醒墙5 属性 × 5 阶，符文 + 大催化剂（日产 1 个的节奏闸门）25 天长墙：月级目标
装备墙六件套 +15（单件 ×1.15 递增）+ 副词条持续，无上限无限墙：长线追求

"毕业 ≠ 满级"是刻意设计：四层墙周期比约为 1 : 3 : 8 : ∞，任何时间点玩家都恰好面对一面正在爬的墙。

1.3 校验闭环

校验页对经验 / 金币 / 大催化剂 / 符文四条资源线分别比对"总需求 vs 目标周期内供给"：经验线按目标周期精确闭环（45 × 150,000 = 6,750,000）；金币线大幅达标——结余转入长线装备养成与多英雄平行培养，符合"毕业不是终点"的品类设计。校验页同步内置 90 天成长模拟与五条完成度曲线，第 45 天综合完成度 100%，验证目标周期设定成立。

二．经济系统全局表

以"标准玩家画像"（零充 / 轻付费）为参数源，对天空石、金币、体力、荣誉四种货币做 90 天逐日收支模拟：余额公式逐日累计，天空石含周期性十连支出（每 30 天一次），金币余额曲线直接可视化通胀压力。

货币90 天收支运营结论
天空石收 17,550 / 支 11,550 / 结余 +6,000投放克制、结余为正——硬通货紧缩是抽卡节奏的核心，补充依赖活动赠送招募券（不占天空石）
金币收 3,600 万 / 支 1,080 万 / 结余 +2,520 万净投放大幅为正（长线通胀）——必须设计回收口：装备重铸 / 限时商店 / 多英雄平行培养
体力收 81,000 / 支 76,500 / 结余 +4,500紧平衡（日均结余 50）——体力是日活闸门：玩家永远"差一点"
荣誉收 27,000 / 支 22,500 / 结余 +4,500微正结余——专用币允许小幅盈余，商店定期上新消耗库存

方法论要点：经济是流量系统——逐日收支模拟比"拍一个总产出"更能暴露通胀时点与缺口。

三．战斗公式设计与行动验证

3.1 回合制口径

《第七史诗》为回合制游戏（跑条决定行动顺序），因此全部战斗度量采用单次行动期望伤害与击杀所需轮数（轮 = 我方 4 英雄各行动一次），不使用实时时间度量。速度（跑条）的价值 = 行动份额：行动次数 ∝ 速度比。

3.2 公式结构

组件公式设计意图
单次行动伤害攻击 × 技能倍率 × 防御减免 × 暴击期望 × 克制修正 × 命中率五因子独立，逐项可调
防御减免K / (K + 防御)，K=1000边际收益递减：防秒杀但不无解
暴击期望1 + 暴击率 × (暴伤 - 1)率与伤乘算，抑制单一堆叠
击杀所需轮数目标生命 ÷ 团队每轮伤害回合制平衡判据

3.3 行动验证与轮数平衡

行动验证表以 8 组典型配置（标准输出 / 平民 / 克制爆发 / 被克 / 极端堆攻 / 极端堆暴 / 防御型 / 毕业）全公式计算单次行动期望伤害：极端堆攻（9000 攻 / 10% 暴）与极端堆暴（3500 攻 / 90% 暴）期望接近——乘算设计天然抑制单一堆叠；被克阵容伤害约为克制的 54%，克制环有策略权重不一击定胜负。轮数平衡校验以四英雄团队每轮伤害对三类目标（小怪 2 轮 / 精英 5 轮 / Boss 10 轮）判定节奏达标。

四．数值结构拆解案

从成品反推设计意图，三条线：

养成周期：分层墙周期比约 1 : 3 : 8 : ∞（等级 / 升星 / 觉醒 / 装备），"毕业不是终点而是分层兑现"。卡池期望：五星英雄 1.25%、保底 121 抽（公示口径）——保底截断重尾分布，期望约 95 抽、最差 121 抽，单个保底成本 114,950 天空石；硬通货投放刻意克制，抽卡自由度由活动赠送的专用券供给，获取节奏成为运营可调参数。战力曲线：战力 = 确定性成长（等级/星级/觉醒）+ 随机性成长（装备副词条），随机性由重铸系统对冲——两者必须成对出现，缺一即流失源。
